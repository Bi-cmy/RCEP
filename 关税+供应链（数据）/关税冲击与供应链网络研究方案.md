# 关税冲击与供应链网络研究方案

## 1. 研究主题

**主题**：美国对华关税冲击如何通过跨国供应链网络传导，并影响中国企业的网络重构、经营表现与脆弱性。

**核心方法**：基于产品关税暴露度、企业供应链网络与财务结果的联合建模，结合面板实证与图神经网络方法，研究关税冲击在供应链网络中的扩散、放大与缓冲机制。

**总体定位**：这不是单纯的“关税对企业绩效影响”研究，而是一个“政策冲击如何沿供应链网络传播”的网络经济学与时空图学习研究。

---

## 2. 核心研究问题

### 2.1 主问题

美国对华关税提高之后，中国企业面临的关税暴露度是否显著上升，并通过中美供应链关系网络传导为：

1. 美国客户或供应商关系的断裂、替代与重构；
2. 企业网络位置的变化；
3. 企业经营绩效、偿债能力、盈利能力与现金流的恶化；
4. 脆弱性更高、中心性更强的企业受到更强冲击。

### 2.2 子问题

1. 关税冲击是否首先影响高暴露行业，再向企业层扩散？
2. 网络中心性是否放大关税冲击？
3. 美国客户依赖度高的企业是否更容易断链？
4. 企业是否通过客户替代、市场重构、网络重构来缓冲冲击？
5. 图神经网络能否更好地识别和预测供应链重构与风险暴露？

---

## 3. 研究假说

### H1：关税暴露效应

企业关税暴露度越高，其中美供应链关系越容易发生断裂、弱化或替代。

### H2：网络放大效应

在相同关税暴露下，网络中心性越高、越依赖美国客户或供应商的企业，受到的经营冲击越大。

### H3：脆弱性差异效应

客户集中度高、收入依赖度强、替代能力弱的企业，在关税冲击下会表现出更强的利润下降和现金流收缩。

### H4：网络重构缓冲效应

能够更快完成客户替代、供应链重连和市场再配置的企业，其财务恶化程度更低。

### H5：图结构增益

相较于传统面板模型，仅使用企业自身特征不足以完整刻画冲击传导；引入供应链图结构后，模型对风险传播和边重构的解释力与预测力显著提高。

## 6. 变量设计

## 6.1 核心解释变量：企业关税暴露度

设企业 \(i\) 属于行业 \(s(i)\)，产品 \(k\) 在该行业中的 2016 年出口权重为 \(W_{k,s(i),2016}\)，则：

\[
TariffExposure_{i,t}=\sum_{k \in s(i)} W_{k,s(i),2016}\times FinalTariff_{k,t}
\]

### 构造步骤

1. 从最终税率表读取 `商品编码/hs2017/year/最终关税`；
2. 从海关表读取 2016 年产品出口额 `人民币`；
3. 通过 HS -> GB2017 行业映射，将产品归入行业；
4. 在行业内按 2016 年出口额构造固定权重；
5. 将企业映射到行业；
6. 对企业所属行业内的产品税率加权求和，得到企业级暴露度。

### 替代口径

1. 使用 `基础税率` 单独构造 MFN 暴露度；
2. 使用 `301关税` 单独构造对华惩罚性关税暴露；
3. 使用 `232关税` 单独构造钢铝冲击暴露；
4. 使用 WITS/WTO 平均税率代替 DataWeb；
5. 使用年度与月度两种时间聚合口径。

## 7. 图数据构建方案

## 7.1 图类型选择

建议分三层递进。

### 方案 A：企业单层图

- 节点：企业；
- 边：供应链关系；
- 时间：年度；
- 优点：最稳，最适合先做；
- 适合任务：边预测、节点风险预测。

### 方案 B：企业-行业二部图

- 节点：企业 + 行业；
- 边：企业属于行业、企业与企业供应链边；
- 适合任务：把行业暴露度更自然地传导到企业。

### 方案 C：企业-产品-行业异构图

- 节点：企业、HS 产品、GB 行业；
- 边：企业-行业、行业-产品、企业-企业；
- 优点：最完整使用全部数据；
- 缺点：工程量最大；
- 适合后续升级，不建议作为第一版。

**建议**：论文主模型采用方案 A，扩展模型采用方案 B，附录或后续版本再做方案 C。

## 8. 面板实证设计

图神经网络适合预测与传播机制表达，但论文中仍建议配套传统实证回归，以强化经济解释与识别透明度。

## 8.1 基准双向固定效应

\[
Y_{i,t}=\beta Exposure_{i,t}+\gamma Controls_{i,t}+\mu_i+\lambda_t+\varepsilon_{i,t}
\]

其中：

- \(Y_{i,t}\)：财务结果或网络结果；
- \(Exposure_{i,t}\)：企业关税暴露度；
- \(\mu_i\)：企业固定效应；
- \(\lambda_t\)：年份固定效应。

## 8.2 网络放大机制

\[
Y_{i,t}=\beta_1 Exposure_{i,t}+\beta_2 Network_{i,t}+\beta_3 Exposure_{i,t}\times Network_{i,t}+\mu_i+\lambda_t+\varepsilon_{i,t}
\]

重点看交互项：

- 暴露度 × 点度中心性；
- 暴露度 × 特征向量中心性；
- 暴露度 × 美国客户依赖度；
- 暴露度 × 客户集中度。

## 8.3 动态事件研究

围绕关键时间点构造事件窗口：

- 2018-07-06：301 清单 1；
- 2018-08-23：301 清单 2；
- 2018-09-24：301 清单 3；
- 2019-05-10：清单 3 升税；
- 2019-09-01：清单 4A；
- 2020-02-14：清单 4A 降税；
- 2024-01-01：14 项豁免；
- 2024-06-15：164 项豁免；
- 2025 起：芬太尼/对等关税。

可将企业按照初始暴露度分组，做高暴露组与低暴露组的动态对比。

## 8.4 稳健性

1. 替代税率口径：WITS/WTO 替代 DataWeb；
2. 替代暴露构造：仅 301，或仅 232；
3. 替代行业映射：GTAP 聚类；
4. 剔除极端值；
5. 客户关系定义替代：只保留 `CUSTOMER/SUPPLIER`；
6. 美国方向边与中国方向边分开估计；
7. 汇率控制；
8. 使用月度海关数据进行时间加权变体。

## 9. 图神经网络研究设计

## 9.1 总体策略

建议采用“三层模型路线”。

### 第一层：经典机器学习基线

- Logistic Regression
- Random Forest
- XGBoost
- 面板回归

目的：

1. 建立可解释基线；
2. 验证图模型是否真正带来增益。

### 第二层：静态图模型

- GCN
- GraphSAGE
- GAT

任务：

- 节点回归：预测下一期利润或风险；
- 边分类：预测下一期边是否断裂。

### 第三层：时空图模型

- GCN + GRU
- GAT + LSTM
- Temporal Graph Network
- Dynamic GraphSAGE

任务：

- 动态传播预测；
- 时序重构识别；
- 冲击扩散路径建模。

## 9.2 推荐主模型

### 模型一：GAT + Temporal Encoder

原因：

1. 供应链边具有异质性，注意力机制能捕捉关键关系；
2. 企业所受冲击可能由少数关键美国客户放大；
3. 时间维可通过 GRU/LSTM 建模。

形式上：

1. 每期图先做 GAT 聚合；
2. 将各期节点嵌入送入 GRU；
3. 输出下一期节点或边预测。

### 模型二：Heterogeneous GNN

若要更完整使用全部数据，可将企业、行业、产品组成异构图：

- 企业 <-属于-> 行业；
- 行业 <-覆盖-> HS 产品；
- 企业 <-交易-> 企业。

这样可以直接学习“产品税率冲击如何经行业层传导到企业，再经供应链边扩散”。

但这更适合作为第二阶段扩展。

## 9.3 具体任务设计

### 任务 A：边断裂预测

标签：

- 当前存在的中美边，下一期是否消失。

输入：

- 当前节点特征；
- 当前边特征；
- 当前企业暴露度；
- 当前图结构。

意义：

最贴合“关税冲击对供应链影响”这一主题。

### 任务 B：节点风险预测

标签：

- 下一期净利润是否显著下降；
- 下一期是否进入高脆弱组；
- 下一期是否发生客户显著流失。

意义：

衡量供应链传导的企业层后果。

### 任务 C：网络重构预测

标签：

- 企业下一期新建替代边数量；
- 企业拓扑重构指数是否跃升。

意义：

衡量适应性和缓冲行为。

## 9.4 模型评价指标

### 对分类任务

- AUC
- F1
- Precision
- Recall
- PR-AUC

### 对回归任务

- MAE
- RMSE
- \(R^2\)

### 对图任务

- Hit@K
- MRR
- Edge prediction AUC

## 9.5 与传统模型的比较

必须设置以下比较组：

1. 只用财务和行业变量；
2. 财务 + 行业 + 关税暴露；
3. 财务 + 行业 + 暴露 + 传统网络统计量；
4. 图神经网络全模型。

如果图模型没有显著优于组 3，就说明“复杂模型没有带来有效结构增益”。

## 11. 识别难点与当前数据问题

## 11.1 已确认的数据问题

1. `处理后的数据/税率数据/基础+芬太尼+对等+232+301+最终.xlsx` 中仍残留极端哨兵值，`基础税率` 最大值为 `9999.999999`；
2. `处理后的数据/税率数据/301附加关税/2018年8月23日-清单2.txt` 目前为空；
3. `处理后的数据/税率数据/232关税/232条款-铝产品.txt` 中存在截断编码，如 `6603.90.`；
4. 最终税率表中 `芬太尼+对等` 当前为空；
5. 当前目录可见的 FactSet `.dta` 更像公司基础表，不是关系主表，供应链原始关系源文件需进一步核对。

## 11.2 识别层面的难点

1. 企业可能主动调整出口结构，造成内生性；
2. 供应链关系存在披露偏差与存续滞后；
3. 2015-2016 财务样本期偏短，与 2018 后关税高峰存在时间错位；
4. 企业与产品之间缺少直接一一映射，只能通过行业层桥接；
5. 232 部分产品存在按钢/铝含量征税问题。

## 11.3 应对策略

1. 采用 2016 固定基期权重；
2. 优先研究网络结果变量，弱化短财务面板限制；
3. 先做中美关系边预测与重构识别，再扩展到财务后果；
4. 对 232 做基础版与保守版两套口径；
5. 使用多税率来源做稳健性。
