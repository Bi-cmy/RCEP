# RCEP 选题探索 — 选题设计（基于四路文献调研 + REPC 数据）

> 四路调研确认：RCEP×**中国HS6产品级** 来源集中度/中间品多元化的**因果识别**无人做过。
> 核心空白：把"来源国HHI/有效供应商数/来源份额"作为**结果变量**、以RCEP差异化降税为**处理**、用**中国HS6×来源国数据**做DID/事件研究——T∩O∩C 为空。

---

## 共同的设计底座（规避REPC已暴露的"日本主导"坑）

REPC 主回归（14国平均）卡在"日本占91.5%变异"。三个规避策略：
1. **用产品/规则维度做异质性**（BEC中间品 vs 最终品），而非14国平均
2. **聚焦特定伙伴组**（中日FTA/东盟）而非全体平均
3. **结果变量用来源构成**（HHI/份额/供应商数），识别"再配置"而非"总量"

## 候选选题

### 选题1：RCEP 是否降低中国进口来源的地缘集中度？

- **RQ**: RCEP 降税是否使中国 HS6 产品的进口来源国更分散（HHI↓ / 有效供应商数↑）？
- **处理**: RCEP 增量降税（产品×伙伴）
- **结果**: `supplier_hhi` / `supplier_effective_number` / `largest_supplier_share`（REPC已构建）
- **识别**: 产品×年份 双向FE + RCEP降税暴露度连续处理；事件研究预趋势
- **规避日本主导**: 结果变量是"来源国构成"整体，不依赖单一伙伴
- **空白**: **T∩O∩C 真空**

### 选题2：RCEP 累积原产地规则下的中间品采购多元化

- **RQ**: RCEP 降税对**中间品（BEC）**进口来源分散化是否强于**最终品**？
- **处理**: RCEP 增量降税 × BEC中间品虚拟
- **结果**: 来源HHI / 来源份额
- **识别**: 三重交互（降税×中间品×Post）+ 产品/伙伴/年FE；预趋势
- **规避日本主导**: 用**产品属性差异**（中间品vs最终品）做识别，不需14国平均
- **空白**: 理论有（Bombarda & Gamberoni 2013），实证无

### 选题3：中日首次FTA的"首次效应"——RCEP 对中日贸易/来源的影响

- **RQ**: 中日首次FTA（RCEP）是否显著改变中国自日本进口/来源份额？
- **处理**: 日本对华降税幅度（日本是唯一"首次FTA"，变异最大）
- **结果**: 日本进口份额 / 自日进口额
- **识别**: 日本产品×伙伴×年，处理强度=日本降税
- **规避日本主导**: 直接"接受"日本主导，把论文定位为"中日首次FTA"（README已明确此边界）
- **空白**: 文献确认"中日专项无人做减式识别"

### 选题4（备选）：贸易便利化的调节作用

- **RQ**: 伙伴国 LPI/海关效率高的，RCEP 降税是否更转化为实际贸易？
- **处理**: RCEP降税 × 伙伴LPI
- **结果**: 贸易额
- **识别**: 三重交互 + 伙伴/产品/年FE
- **空白**: 文献确认无"LPI×RCEP关税"交互项

## 下一阶段：逐选题跑「双固定效应主回归 + 预趋势」

对每个选题：
1. 确认数据字段
2. 跑双向FE（产品+年）主回归 + 三重FE（伙伴-产品/产品-年/伙伴-年）敏感性
3. 跑事件研究预趋势（联合Wald p）
4. 判断可实现性：主回归方向合理 + 预趋势通过 = **可实现**；否则如实记录失败
5. 归档到 `audit/选题N/`
