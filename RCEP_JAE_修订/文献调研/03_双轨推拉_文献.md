## 0. 总结论（一句话）

现有文献**几乎没有人把"美国关税冲击"与"RCEP 区域协定"作为两个可交互的冲击，放在**同一个**中国上市企业（micro / firm-level）框架里**同时建模。已有组合二者的研究，要么停留在**国家/贸易集团/宏观 CGE**层面（如 Petri–Plummer–Park 2021），要么把冲击落在**第三国（越南、泰国、东盟）**的出口上，要么只分别单独研究"中国企业的脱钩/再挂钩"or"RCEP 贸易创造/转移"。本文构建的"美国关税（Push）× RCEP（Pull）双轨推拉 + 中国上市公司供应链重构"框架具备**明确的边际贡献（novelty）**。

## 2. 核心判断

### 2a) 是否已有人"把美国关税和 RCEP 放进同一个中国企业级框架"？

**结论：没有（至少在可检索的正式文献里，明确缺位）。**
- 已把二者放进同一框架的，只有两类：
  1. **宏观/CGE/国家聚合层面** —— Petri–Plummer–Park (2021, EAER)、*Trade War, RCEP and CPTPP* (SSRN)、越南–中国双边 ARDL (2024)。它们有"双轨"，但**没有企业异质性、没有企业级供应链（客户/供应商/子公司）数据**，无法回答"同一家企业如何同时被推拉两地"。
  2. **第三国/单国产业层面** —— 越南纺织 RCEP 套利 (2026)、越南/泰国/东盟的贸易转移与 FDI。它们落在**中国以外的经济体或单一产业**，不是**中国上市企业**。
- 真正落在**中国上市企业（CSMAR + FactSet + 关税线数据）**上、**同时**以**美国关税（Push）+ RCEP（Pull）为两个可交互处理**的研究，**未检索到**。这一结论经 Crossref 多组靶向查询与 Semantic Scholar 交叉验证确认。

### 2b) "双轨"角度的独特性（novelty 论证）

本文的双轨设计相对现有文献有**三重独特性**：

1. **微观主体层面的空白**：现有"双轨"研究是宏观 CGE（Petri et al.）或国家双边 ARDL（越南–中国）。本文将同样的"推-拉"结构下沉到**中国上市企业**，能在企业内/企业间识别异质响应——哪些企业被美国关税"推出"、被 RCEP"拉入"，以及二者的交互。

2. **"两个可交互处理"而非两个平行故事**：以往文献要么只讲"脱钩/再挂钩"（单一 Push），要么只讲"RCEP 贸易创造/转移"（单一 Pull）。本文的意义在于**交互项**——RCEP 作为"保险/安全阀"，**能否缓冲美国关税冲击**（push 被 pull 部分对冲），或**放大**再配置（push 把企业推向 RCEP 内部市场）。这一"双轨联动、轨道间对冲/放大"的机制，是此前"分别单轨"研究做不到的。

3. **数据组合的独特性**：现有企业级贸易战研究多用**海关/订单/出口数据**，且集中在**美方（进口侧）或第三国企业**。本文使用 **USITC HTS-10 关税表 × FactSet（全球客户/供应商/子公司/标的地理网络）× CSMAR（中国上市公司财务与治理）** 三者联动，能在**同一家企业**上同时刻画：①对美关税暴露（Push 强度）、②对 RCEP 成员暴露/原产地规则的适用度（Pull 强度）、③供应链重构结果（出口目的地再配置、客户/供应商切换、对东盟的海外子公司/绿地投资、营收与韧性）。**这种"关税线 × 商业关联网络 × 中国上市企业财务"的企业级三源拼图在文献中未见先例。**

### 2c) 用已有数据（美国关税表 + FactSet + CSMAR）能做什么

建议的实证设计（对已有数据的"变现"）：

- **处理变量（两个）**：
  - **Push（美国关税暴露）** = 用 USITC Section 301 HTS-10 关税表 + 企业出口/产品结构，构建企业层面的**加权对美关税暴露度**（exposure * share-of-US-sales），区分贸易战各轮（2018–2019、2025 升级）。
  - **Pull（RCEP 暴露）** = 企业产品的 RCEP 关税减免幅度 + 企业对 RCEP 成员的贸易占比 + 关键**原产地累积规则**（RCEP 允许成员国内原产累积 → 中间品来自 RCEP 成员即可享优惠）的适用性；也可用 FactSet 口径的企业在东盟/日韩澳新等 RCEP 成员的子/关联公司布局作为"已有拉入程度"。
- **结果变量（供应链重构）**：出口/营收的**目的地再配置**（美→非美、是否转向 RCEP 成员）、**客户/供应商切换**（FactSet 客户-供应商关系）、**海外子公司/绿地投资**（是否在东盟设立/并购，FactSet ownership）、**供应链韧性与波动**（收入/毛利波动、韧性指标）、**全球价值链分工位置**。
- **识别策略**：
  - **DID / staggered-DiD**，以"对美高暴露 + 对 RCEP 高暴露"的两个暴露度作处理强度；
  - **交互项识别"双轨联动"**：核心检验 `SupplyChainReconfiguration = β₁·US_tariff_exposure + β₂·RCEP_exposure + β₃·(US×RCEP) + X·γ + FE`，`β₃` 即"RCEP 缓冲 vs 放大美国关税"的证据；
  - **安慰剂 / 排除性检验**：非 RCEP 亚洲成员（如印度、美国本身）作对照，验证"拉入"仅来自 RCEP 规则而非泛亚洲地理就近；
  - **PB 类稳健性 + 平行趋势 + 事件研究**，呼应本课题现有的 identification 库。
- **样本与微观定位**：CSMAR 中国 A 股上市制造/出口企业 + FactSet 关联的海外客户/供应商/子公司 + 美国关税线的 HTS 匹配。此设计正好填补 2a/2b 指出的空白。

- 主要**局限**：Crossref 的 `query.bibliographic` 召回偏宽（含农业/旅游/环保等噪声），已按主题关键词二次过滤；部分小期刊（尤其中文/俄文/印尼文期刊）摘要缺失，仅凭标题与刊名判断。结论经多组靶向查询互证，未见中国企业级"双轨"论文，但**不能排除未收录于 Crossref 的中文数据库（知网/万方）内存在同类研究**——建议正式投稿前另用 CNKI 复核一次。
