# Experiment 08: quantified relationship dependence

## Question

Did RCEP change active-link persistence differently for relationships that
FactSet quantified as representing a larger revenue percentage?

## Measurement limit

`revenue_percent` is not trade value. It is available for only about nine
percent of source relationship records. The exposure is frozen only from
episodes beginning by 2021-12-31; the full-period maximum in the existing
pair-year file is not used.

## Final status

Failed at the frozen moderation pretrend gate. Data support passed, but the
joint revenue-percentage lead test strongly rejected and the lead magnitude
was economically large. No static moderation coefficient was estimated. See
`archive/decision.md`.
