# Experiment 03: first supplier-country entry

## Question

After RCEP entry, did covered Chinese listed firms become more likely to enter
previously unconnected RCEP supplier countries than previously unconnected
Asian non-RCEP countries?

The unit is a listed-firm/candidate-country/year risk-set observation. The firm
universe is fixed using 2017 supplier coverage only. Firm-by-year fixed effects
compare candidate countries within the same firm and year.

## Current phase

The PAP is frozen. No risk-set support statistic or effect estimate has been
inspected. The next step is to build and validate the candidate-country panel.
