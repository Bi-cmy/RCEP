# Experiment 09: support-informed cross-architecture landmark design

This is a new, explicitly support-informed experiment. Before PAP freeze, the
support audit from Experiment 07 was known: 2,556 balanced firms, 261 with at
least one architecture, and 52 with at least two. No pretrend or policy-effect
coefficient for this design had been estimated or inspected.

Exposure uses 2017-2019 supplier links; outcomes use 2020-2024. The primary
question is whether RCEP supplier-link intensity changed more after 2022 for
firms whose sourcing already crossed more previously separate trade-agreement
architectures.
