# Experiment 02: incumbent relationship survival

## Question

Did RCEP entry change the survival path of supplier relationships that were
already active before the policy?

This experiment fixes a 2017 year-end cohort and follows it from 2018 through
2024. The design therefore has four policy-free follow-up years for the main
2022 cohort and does not define treatment groups using later survival outcomes.

## Current phase

The PAP is frozen. The next step is a cohort-support audit. No survival-effect
or event-study estimate has been inspected.
