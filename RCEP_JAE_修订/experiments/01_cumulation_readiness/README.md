# Experiment 01: regional cumulation readiness

## Question

After RCEP entered into force, did Chinese listed firms with stronger
pre-policy multi-country RCEP sourcing foundations exhibit different supplier
relationship exit, entry, and diversification outcomes?

The exposure is a predetermined network-position proxy. It does not observe
certificate use, tariff preference claims, or actual compliance with product-
specific rules of origin.

## Current phase

The PAP and data definitions are frozen. No new outcome regression has been
inspected. The next task is to build the firm-year panel and complete the
support, mapping, and pre-trend diagnostics specified in `pap/pap.json`.

## Directory map

- `pap/`: frozen empirical design.
- `code/`: reproducible scripts for this experiment only.
- `data/`: contract, sample log, and experiment-specific derived data.
- `tables/`: XLSX, DOCX, and TEX outputs.
- `figures/`: PDF and 300-DPI PNG outputs.
- `logs/`: environment and execution logs.
- `archive/`: final decision and failure/inconclusive explanation.
