# Experiment 05: supplier-customer asymmetry

## Question

Did RCEP change supplier-link intensity differently from customer-link
intensity within the same covered firms and partner-country-years?

The model absorbs partner-country-by-year effects, firm-by-year-by-role effects,
and firm-by-country-by-role effects. It identifies a supplier-versus-customer
difference, not the average RCEP effect.

## Final status

Archived as inconclusive. The support and pretrend gates passed, but the
preferred static estimate did not pass the frozen country-label randomization
gate. See `archive/decision.md` for the complete decision trail.
